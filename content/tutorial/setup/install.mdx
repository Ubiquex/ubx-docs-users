By the end of this tutorial you'll have `ubx` installed and a real,
working config file for one stack, ready for the next tutorial to
actually author something against.

## Install ubx

Two real ways to install, pick one.

<Tabs>
  <Tab title="GitHub Releases">
    ```bash
    curl -L https://github.com/Ubiquex/ubiquex/releases/latest/download/ubx_<version>_<os>_<arch>.tar.gz | tar xz
    sudo mv ubx /usr/local/bin/
    ```
    Replace `<version>`, `<os>` (`darwin` or `linux`), and `<arch>`
    (`amd64` or `arm64`) to match your machine.
  </Tab>
  <Tab title="Build from source">
    ```bash
    git clone https://github.com/Ubiquex/ubiquex.git
    cd ubiquex
    go build -o ubx ./cmd/ubx
    sudo mv ubx /usr/local/bin/
    ```
    Requires Go 1.26 or later.
  </Tab>
</Tabs>

Confirm it worked:

```bash
ubx version
```

```bash
0.2.0+8f2a1b3
```

## Create a stack directory

```bash
mkdir payments && cd payments
```

## Write a config

`ubx init` writes the config file every other command reads.

```bash
ubx init --dynamic-source ubiquex/aws --provider-version 4.0.0
```

You'll see:

```bash
+ .ubx/config.hcl has been generated successfully
    see https://docs.ubiquex.io/cli-reference/config
next: install this provider's bindings (`npm install @ubx/sdk-aws`), write stack.ts, and run `ubx plan` -- see https://docs.ubiquex.io/cli-reference/config
```

Take a look at what it actually wrote:

```bash
cat .ubx/config.hcl
```

```bash
stack = "payments"

providers = {
  "aws" = {
    source  = "ubiquex/aws"
    version = "3.0.0"
  }
}
```

Two real values, nothing else. Every other setting has a sensible
default until you need it.

<Note>
  No region here, and no credentials. A ubx dynamic provider takes both
  from the pinned snapshot named above, fixed when that snapshot was
  built, so they are a property of the pin rather than of your stack.
  `ubx init` refuses `--region` and `--provider-config` on this path
  rather than writing settings the provider would reject. If you need a
  different region, pin a snapshot built for it, or use a Terraform
  registry provider with `--source`, which does take per-stack provider
  configuration.
</Note>

## Confirm it resolves correctly

```bash
ubx config
```

```bash
providers.aws.source = ubiquex/aws  <- /Users/you/payments/.ubx/config.hcl
providers.aws.version = 3.0.0       <- /Users/you/payments/.ubx/config.hcl
stack = payments                    <- /Users/you/payments/.ubx/config.hcl
cascade stopped at: filesystem root (/)
```

## What you just did

You installed a real binary, and `ubx init` wrote a real, minimal
config, a stack name and a pinned provider version, nothing commented
out, nothing you'll have to come back and fill in later. `ubx config`
confirmed both values and named the exact file that supplied each one.
